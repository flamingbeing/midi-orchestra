# Sample and impulse-response sources

The pipeline loads only the files kept here. They are copied unchanged from the original free libraries, and each library keeps its own licence, listed below. Some licences are non-commercial: they allow sharing these files and the renders made with them, but not selling them.

| Folder | Library | Licence | Used for |
| --- | --- | --- | --- |
| `samples/VSCO-2-CE_git/` | Versilian Studios Chamber Orchestra 2, Community Edition ([GitHub](https://github.com/sgossner/VSCO-2-CE)) | CC0 1.0 | Violin, viola and cello sections (sustain, pizzicato) and the clarinet (3 dynamic layers) |
| `samples/sso_git/` | Sonatina Symphonic Orchestra (Mattias Westlund) | Creative Commons Sampling Plus 1.0 | Celesta |
| `samples/tiny-orchestra/` | tiny-orchestra npm package, a compact VSCO-2 subset ([GitHub](https://github.com/MarianBecher/tiny-orchestra)) | CC0 1.0 | Glockenspiel, snare, timpani, oboe, contrabass and others |
| `samples/tonejs-instrument-*-wav/` | tonejs-instruments WAV packages ([GitHub](https://github.com/Makefully-Studios/tonejs-instruments)) | MIT (as the npm packages declare it) | Flute, piano, nylon guitar, harp, xylophone, horn, trumpet and trombone |
| `hall/marco_tree/` | 3D-MARCo, St Paul's Hall, Huddersfield: per-seat impulse responses rebuilt as a Decca tree plus a Hamasaki ambience pair (see `hall/README.txt`) | CC BY-NC 3.0 | Concert-hall reverb (each instrument plays from its own measured seat) |

**Attribution for the hall:** "3D-MARCo, Hyunkook Lee & Dale Johnson, Applied Psychoacoustics Lab, University of Huddersfield (zenodo.org/records/3477602)".

`hall/seating.json` maps each instrument to a stage position.
